## Повідомлення для партнера

_Що стало доступним кодеру B і про що треба домовитись. Нові — зверху._

- **A5 готовий: сервер завершено.** `npm run build && npm start` роздає `client/dist` на :3001 (SPA-фолбек для `/host/:pin`, `/play/:pin` тощо), `/api/*` завжди відповідає JSON. Кімната живе 2 години, потім `room:closed` усім її сокетам. Зі сторони сервера SP3 готова — чекає B6.

- **A4 готовий: боти.** Запусти `npm run dev:server`, потім `npm run bots -- --autohost --lobby-wait 30` — скрипт створить кімнату, надрукує PIN і адресу `http://<LAN-IP>:5173/?pin=<PIN>`, і за 30 с можна зайти з вкладки як гравець; далі він сам тисне «Далі». Боти в наявну кімнату: `npm run bots -- --pin <PIN> --count 12`. Усі прапорці: `npm run bots -- --help`.

- **A3 готовий (SP2).** Після мерджу в `main` сервер грає повну гру за §6.3–§6.6: `host:next`, `player:answer`, авто-`reveal` за таймером і коли відповіли всі підключені, бали за швидкість, `finished`. Можна виконувати B5. Ботів ще немає (A4), але гру вже видно через `npm run smoke`.

- **A1 готовий (SP1).** Після мерджу в `main` працює весь REST з §6.1: `GET/POST /api/quizzes`, `GET/PUT/DELETE /api/quizzes/:id`, `GET /api/config`. Можна виконувати B4. Демо-квізи мають ліміти часу лише 10 і 20 с — обидва є в `TIME_LIMIT_CHOICES`, тож `select` редактора їх покаже.
