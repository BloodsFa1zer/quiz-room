# QuizRoom

Квіз-платформа реального часу: ведучий запускає квіз на ноутбуці, учасники заходять із телефонів за PIN-кодом або QR, відповідають на час і бачать таблицю лідерів. Навчальний проєкт на TypeScript: Express і Socket.IO на сервері, React на клієнті.

## Вимоги

- Node.js ≥ 22.12
- npm

## Запуск

```bash
npm install
npm run dev
```

- Клієнт: http://localhost:5173
- Сервер: http://localhost:3001 (перевірка — http://localhost:3001/api/health)

Телефони в тій самій мережі відкривають `http://<IP ноутбука>:5173`.
