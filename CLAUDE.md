# QuizRoom

Студентський демо-проєкт: квіз-платформа реального часу (Express + Socket.IO + React, TypeScript, npm workspaces). Код генерують два незалежні ШІ-кодери за планом у `docs/`: A — сервер, B — клієнт.

- План, контракт і правила: `docs/00-common.md`.
- Етапи сервера: `docs/A-server.md`. Етапи клієнта: `docs/B-client.md`.
- Будь-який етап плану виконуй через скіл `/quiz-stage <ID>`; стан робіт — `/quiz-stage status`.

Правила, які діють завжди, також поза етапами (повністю — R1–R12 у `docs/00-common.md` §5):

- Змінюй тільки свою зону: A — `server/**` і `README.md`; B — `client/**`. Роль задає стартовий промпт або ID етапу. Якщо незрозуміло, яка в тебе роль, — спитай, перш ніж щось змінювати.
- `shared/**` і кореневі конфіги заморожені: це контракт між двома кодерами.
- Не додавай залежностей — зміна `package-lock.json` ламає роботу другому кодеру.
- Це демо, а не продакшн: без авторизації, БД, Docker, CI.
- Пиши найпростіший код, який студент зможе пояснити на захисті.
- Кажи «працює» тільки після того, як запустив перевірку й побачив результат.

Команди: `npm run dev` · `npm run typecheck` · `npm test` · `npm run smoke` · `npm run build`.
